# Локальный запуск

Фронтенд и бэкенд лежат в разных репозиториях. Фронтенд, бэкенд и БД запускаются отдельно и обмениваются данными локально

| Компонент           | Адрес                    | Назначение                             |
| ------------------- | ------------------------ | -------------------------------------- |
| Сервер фронтенда    | `http://localhost:18080` | Отдает браузеру HTML, CSS и JavaScript |
| Бэкенд              | `http://localhost:5245`  | Принимает запросы API и работает с БД  |
| PostgreSQL в Docker | `localhost:5432`         | Хранит места и подборки                |

Браузер получает файлы с сервера фронтенда. Затем JavaScript в браузере запрашивает данные у API, а бэкенд читает их из PostgreSQL

## Запуск БД и бэкенда

Перед первым запуском выполнить [подготовку и импорт](setup.md)

В первом терминале (указать путь):

```bash
cd underekat
docker compose up -d --wait
dotnet run --project UnderEkat.Api.csproj --launch-profile http
```

- Docker Compose читает `compose.yaml` из папки бэкенда и запускает PostgreSQL
- `-d` оставляет контейнер работать в фоне
- `--wait` ожидает готовности БД
- `dotnet run` запускает API и занимает вкладку до остановки

Проверка API в браузере:

```text
http://localhost:5245/api/v1/places
```

В ответ должен прийти JSON со списком публичных мест

## Запуск сервера фронтенда

В другом терминале (указать путь), если установлен Python 3:

```bash
cd underekat-demo
python3 -m http.server 18080 --bind 127.0.0.1
```

Открыть в браузере:

```text
http://localhost:18080
```

## Обращение фронтенда к API

Пример получения списка мест:

```js
const places = await fetch("http://localhost:5245/api/v1/places").then(
  (response) => response.json(),
);
```

## Остановка

- Во вкладках API и фронтенда нажать `Ctrl+C`
- Если API запущен через Rider, остановить его
- Для остановки БД выполнить из папки бэкенда:

```bash
docker compose stop
```

Данные PostgreSQL сохраняются в Docker volume и остаются после остановки контейнера
